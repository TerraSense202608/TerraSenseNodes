About TerraSense

TerraSense

Intelligent Environmental Monitoring for Smarter and Safer Land Management.

TerraSense is an IoT-based environmental monitoring system designed to collect real-time data from distributed sensor nodes.

🌱 Soil Monitoring

Monitors soil moisture conditions using an analog soil moisture sensor.

🌧 Rain Detection

Detects rainfall conditions using a rain sensor module.

◈ Terrain Stability

Uses MPU6050 accelerometer and gyroscope data to monitor tilt.

☀ Sustainable Power

Future integration with solar power and battery backup.
